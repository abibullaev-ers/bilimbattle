# ⚔️ BilimBattle — Quiz Battle Game Platform

> Білімді ойынмен арттыр | Boost Knowledge Through Games

BilimBattle — мұғалімдерге және оқушыларға арналған интерактивті викторина платформасы. Бірнеше ойын режимдері арқылы сабақты қызықты өткізіңіз!

## 🚀 Live Demo

🔗 [Ойынды ашу / Play Now](https://abibullaev-ers.github.io/bilimbattle)

## ✨ Game Modes

| Режим | Сипаттама |
|-------|-----------|
| 🎯 **Kahoot Style** | Классикалық тест ойыны |
| 👾 **Monster Battle** | Монстрмен шайқас арқылы тест |
| 🎡 **Roulette** | Кездейсоқ сұрақ рулеткасы |
| 🎭 **Bamboozle** | Алдаушы жауаптар режимі |

## 🎮 Features

- 👨‍🏫 **Admin Panel** — Мұғалім басқару тақтасы
- ✏️ **Quiz Editor** — Тест редакторы (AI генерациямен)
- 🤖 **AI Question Generator** — Жасанды интеллект арқылы сұрақ жасау
- 📊 **Dashboard** — Нәтижелер мен статистика
- 🔐 **Auth System** — Тіркелу / Кіру жүйесі
- 🔊 **Sound Effects** — Дыбыстық эффектілер
- 📱 **Responsive Design** — Мобильді дизайн

## 🛠️ Tech Stack

| Technology | Usage |
|------------|-------|
| HTML5 | Structure |
| CSS3 | Styling & Animations |
| JavaScript (Vanilla) | Game Logic |
| AI API | Question Generation |

## 📁 Project Structure

```
bilimbattle/
├── index.html          # Main entry
├── css/
│   ├── base.css        # Base styles
│   ├── auth.css        # Login/Register
│   ├── dashboard.css   # Dashboard
│   ├── editor.css      # Quiz editor
│   ├── game.css        # Game styles
│   └── monster.css     # Monster mode
└── js/
    ├── main.js          # App initialization
    ├── auth.js          # Authentication
    ├── dashboard.js     # Dashboard logic
    ├── editor.js        # Quiz editor
    ├── data.js          # Data management
    ├── game-core.js     # Core game engine
    ├── game-kahoot.js   # Kahoot mode
    ├── game-monster.js  # Monster battle mode
    ├── game-roulette.js # Roulette mode
    ├── game-bamboozle.js# Bamboozle mode
    ├── ai-generator.js  # AI question generator
    ├── sounds.js        # Sound effects
    ├── utils.js         # Utilities
    └── admin.js         # Admin panel
```

## 🎯 How to Use

1. **Мұғалім** — Тіркеліп, тест жасаңыз
2. **Оқушылар** — Бөлме кодын енгізіп қосылыңыз
3. **Ойнаңыз!** — Ұпай жинап бірінші орынға жетіңіз 🏆
